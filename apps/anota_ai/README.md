
# ANOTA  AÍ

### Tecnologia

"Anota aí", é uma aplicação inicialmente feita com tecnologia web: html, css, js e reactjs.

### Descrição

A aplicação possibilita a criação, exclusão, o carregamento de notas.  

### Funcionalidades

* Puxa notas automaticamente quando aberto e ou se clicar no botão com um símbolo com uma seta para baixo.
* Criar notas clicando no botão com símbolo de adição
* Atualizar notas existentes
* Apagar notas existentes
